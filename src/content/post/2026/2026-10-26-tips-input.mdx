TIPS is an HTML input for numbers, but it's a number input built from a text input. I created a [GitHub repo](https://github.com/kevinashworth/input-tips) to publish TIPS wired up as a Preact component, and that repo has a GitHub Pages [demo site](https://kevinashworth.github.io/input-tips/) there for you to play with it.

Compare the browser's native <code>type="number"</code> field with a TIPS input: a <code>type="text"</code> field that uses <code>inputmode</code>, <code>pattern</code>, and <code>size</code> to accept numbers and to return a number value if you are using it for a controlled input in React.

Try it in <strong>dark mode</strong> too: with Firefox (as shown in the screenshot above), the native number field keeps its light-colored arrows in dark mode, while the TIPS input does not. Use TIPS to get rid of that ugliness!
